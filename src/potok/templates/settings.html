Лента с паролем

Логин и пароль нужны, если чужая RSS-лента спрашивает пароль. Пустое поле старое значение не стирает.

Этот раздел решает, какие записи из ленты попадут в очередь на одобрение.

  • Минимальный рейтинг — ниже этого порога фильм пропускается. Пустое поле выключает проверку. Сейчас {{ draft.min_rating or "выключен" }}.
  • Не старше, дней — старше этого срока запись не берётся. Пустое поле выключает проверку. Сейчас {{ draft.max_age_days or "выключен" }}.
  • Жанры — список через запятую. Пустое поле значит любые. Сейчас {{ draft.genres or "любые" }}.
  • Как искать рейтинг, жанр и качество — шаблоны, по которым эти слова вытаскиваются из текста ленты.
  • Какие качества оставлять — если указаны только 2160p и 1080p, копии в 720p в очередь не попадут. Пустое поле — любое качество.
  • Если фильм в нескольких качествах — в очередь попадёт одна копия. Сейчас {{ {"max": "максимальное", "average": "среднее", "min": "минимальное"}.get(draft.quality_keep, "максимальное") }}.
Пустое поле — любое качество. Если в шаблоне только 2160p и 1080p, копии в 720p в очередь не попадут.
Одинаковые фильмы в очереди не повторяются. Максимальное — самая высокая копия. Среднее — ближайшее к 1080p: и рядом с 720p, и рядом с 2160p остаётся 1080p. Если два качества одинаково близки к 1080p, берётся более высокое. Минимальное — самая низкая. Если в очереди уже лежит копия слабее выбранного правила, новая подходящая её заменяет. Более слабая копия выбранную не вытесняет. Среди копий одного качества остаётся раздача с большим числом сидов.

Пароли и ключи в config.yaml не записываются. Пустое секретное поле старое значение не стирает.

Telegram

Как узнать id чата:

  1. Личный чат: в Telegram найдите @userinfobot, нажмите «Запустить» и скопируйте число Id.
  2. Группа: добавьте своего бота в группу и разрешите ему писать. Добавьте туда @getmyid_bot, напишите любое сообщение и скопируйте Chat id вместе с минусом. Потом @getmyid_bot из группы удалите, своего бота оставьте.
  3. Вставьте число в поле «Id чата» и нажмите «Сохранить» внизу страницы.

Id группы начинается с -100. Это же число решает, кто может писать боту команды. Если вписать id группы, сообщения уйдут в группу, а команды в личке бот перестанет принимать.

qBittorrent

Логин и пароль — вход в окно qBittorrent и для команд Потока.

После успешной загрузки видео во VK бот ищет фильм в The Movie Database и присылает карточку с обложкой и данными фильма. Ссылка на VK — кнопка под сообщением. Кнопки «Одобрить» и «Отклонить» остаются на первом сообщении, до загрузки.

Для России сайт закрыт на уровне DNS. Поток спрашивает только адреса themoviedb.org и tmdb.org у сервера 9.9.9.9. Остальные сайты идут через прежний DNS, Jackett и qBittorrent не затрагиваются.

Как получить ключ:

  1. Откройте themoviedb.org и зарегистрируйтесь.
  2. Нажмите значок профиля → «Настройки» → раздел «API».
  3. Нажмите «Запросить API-ключ». Тип — Developer. Заполните короткую форму.
  4. Скопируйте «Ключ API» (API Key, v3 auth). Токен для чтения (v4) сюда не нужен.
  5. Вставьте ключ в поле ниже и нажмите «Проверить ключ».

Проверка ищет фильм «Матрица». Если ключ новый и поиск прошёл, он сразу записывается в зашифрованный data/secrets.enc. В config.yaml ключ не попадает.

Этот раздел говорит, куда заливать видео и как долго ждать VK.

  • Версия API — какую версию методов VK вызывать. Сейчас {{ draft.api_version }}.
  • ID сообщества — в какое сообщество класть ролик. Пустое поле — на свою страницу. Сейчас {{ draft.group_id or "своя страница" }}.
  • Кто видит — кто может открыть ролик. Сейчас {{ dict(privacy_choices).get(draft.privacy_view, draft.privacy_view) }}.
  • Публиковать на стене — сразу сделать запись на стене.
  • Скрытое видео — ролик не показывается в общем списке.
  • Кусок — каким куском файл отправляется в VK, в байтах. Сейчас {{ draft.chunk_bytes }}.
  • Максимум — файл больше этого размера в байтах в VK не отправляется. Сейчас {{ draft.max_bytes }}.
  • Попытки загрузки — сколько раз повторить отправку файла, если связь оборвалась. Сейчас {{ draft.upload_attempts }}.
  • Пауза загрузки — сколько секунд ждать, если отправка замерла. Сейчас {{ draft.upload_idle_timeout_seconds }}.
  • Интервал проверки — как часто спрашивать, готов ли плеер, в секундах. Сейчас {{ draft.poll_interval_seconds }}.
  • Срок проверки — сколько секунд ждать обработку на стороне VK. Сейчас {{ draft.poll_timeout_seconds }}.
  • Таймаут API — сколько секунд ждать один ответ VK. Сейчас {{ draft.api_timeout_seconds }}.
  • Повторы API — сколько раз повторить запрос, если VK временно не ответил. Сейчас {{ draft.api_retries }}.

Токен VK

Страница VK после разрешения пустая. Токен лежит в её адресе. Портал сам вытаскивает его из вставленной строки и запоминает срок.

  1. Впишите ID приложения. У «Потока» это число из короткого адреса, без букв app.
  2. Нажмите «Открыть страницу VK» и разрешите доступ.
  3. На пустой странице скопируйте всю адресную строку.
  4. Вставьте её в поле ниже и нажмите «Сохранить токен».

Открыть страницу VK
